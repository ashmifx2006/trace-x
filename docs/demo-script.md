# 3-minute demo
1. Command Center: numbers are computed from the engine, not hardcoded.
2. Suspicious Networks: open the top circular network.
3. Press Start replay: the graph animates; PATTERN DETECTED fires on the closing hop.
4. Risk tab: every point explained. DNA radar beside it.
5. Compare two networks' DNA. Open a case, add a note, download the PDF dossier.
6. Upload a CSV: the whole pipeline re-runs.
